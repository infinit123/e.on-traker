# Revizio V2

Fișiere pregătite pentru publicare pe GitHub Pages.

## Actualizări
La fiecare versiune publicată, modifică `APP_VERSION` în `sw.js` (de exemplu `2.0.1`). La următoarea deschidere, aplicația verifică versiunea și afișează butonul **Actualizează**. Utilizatorul nu trebuie să dezinstaleze aplicația.

## Important
Publică toate fișierele din pachet în aceeași structură și folosește HTTPS. Datele din localStorage rămân pe dispozitiv la actualizarea aplicației. Folosește periodic Export backup.
